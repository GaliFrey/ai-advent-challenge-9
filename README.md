## Структура

```text
AI_Advent_Challenge/
├── day-XX/          # отдельное задание
│   ├── README.md    # задание, запуск и результаты
│   ├── resources/   # локальные материалы, вне Git
│   └── ...          # код и зависимости дня
├── chats/           # локальные экспорты чатов, вне Git
├── AGENTS.md        # правила работы AI-агентов
├── history.md       # история изменений
├── .gitignore
└── README.md
```

Каждый день — самостоятельный проект. Код и файлы, необходимые для запуска,
хранятся вне `resources/`; расположение остальных артефактов описано в README дня.
Видео, вложения курса и экспорты чатов не добавляются в Git.

Секреты хранятся в локальном `.env` или переменных окружения. В Git допустим
только безопасный `.env.example` без ключей. Общие правила — в [AGENTS.md](AGENTS.md).
