# AI Advent Challenge

Один репозиторий для заданий всего челленджа. Каждый день находится в отдельной папке и может иметь собственные зависимости и инструкции по запуску.

## Дни

- [День 0 — введение](day-00/README.md).
- [День 1 — первый запрос к LLM через API](day-01/README.md).

## Структура

```text
AI_Advent_Challenge/
├── day-00/
├── day-01/
│   └── README.md
├── AGENTS.md
├── .gitignore
├── history.md
└── README.md
```

Видео и экспорт чатов хранятся локально и исключены из Git. Секреты необходимо передавать через переменные окружения; файл `.env` также не коммитится. Для примера допустимо добавлять безопасный `.env.example` без настоящих ключей.

Правила работы AI-агентов с репозиторием зафиксированы в [AGENTS.md](AGENTS.md).
