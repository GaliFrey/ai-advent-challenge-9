# Тюнер для 6-струнной гитары

Страница слушает микрофон, определяет открытую струну стандартного строя
E2, A2, D3, G3, B3, E4 (A4=440 Гц) и показывает отклонение. Аудио обрабатывается
локально в браузере, не записывается и не передаётся.

Кнопка «Помощь» открывает поддержку DeepSeek. До первой отправки показано:
«Ответы формирует DeepSeek. Сообщения, история текущего обращения и состояние
тюнера передаются во внешний AI-сервис. Аудиозапись не отправляется».
AI может ошибаться. Текст и снимок при отправке сохраняются в локальной SQLite.
Backend получает историю и исходный снимок через настоящий MCP; E5-small на CPU
находит материалы только в пользовательских статьях. В DeepSeek отправляется
ограниченный текстовый контекст. Ответ и выбранные источники сохраняются.
Фрагмент можно раскрыть либо открыть как отдельный сохранённый материал;
актуальный индекс для чтения прежнего ответа не нужен. HTML не исполняется.

## Запуск

Из корня проекта посредник/оператор готовит окружение по [README](../README.md):

```bash
uv sync --locked
uv run python -m server.retrieval prepare-model
uv run python -m server.retrieval build-index
uv run --no-sync --offline python -m server.main
```

Настройте DEEPSEEK_API_KEY только на backend (системное окружение либо проектный
.env); модель deepseek-flash. `--offline` относится к uv, рабочий чат требует
сети к DeepSeek. Без ключа сообщение сохранится с понятной ошибкой.
Откройте http://localhost:8000/ и разрешите микрофон кнопкой «Включить микрофон».
Сервер слушает только loopback; страница, статика и API работают с одного origin.
Не смешивайте localhost и 127.0.0.1: cookie принадлежат разным адресам.

История переживает закрытие панели, перезагрузку и перезапуск. «Новый разговор»
создаёт отдельную переписку, сохраняя старую в базе. Во время ожидания тюнер
продолжает работать. После ошибки «Повторить» использует исходный текст, снимок
и ключ без дубля; в истории ошибки после перезагрузки есть отдельная кнопка
повтора. MCP и поиск выполняются заново до исходного сообщения. Завершённый
ключ возвращает сохранённый ответ. Автоповторов нет.

Одна обработка во всём приложении, без очереди; по умолчанию 10 начатых внешних
попыток на сессию за час, в том числе неудачных. Новый разговор не сбрасывает
лимит. Если вопрос превышает 512 токенов E5, отредактируйте его как новый; если
превышен общий контекст, сократите вопрос или создайте новый разговор. После
исправления ключа, сети или индекса повтор разрешён явно. Подробнее —
[API](../docs/support-api.md) и [контракт снимка](../docs/support-context.md).

## Проверки и приёмка

Контроллер запускает backend-, Node-тесты и offline-evaluate retrieval.
Тесты DeepSeek подменяют HTTP и проверяют payload; реальной генерацией они не
являются. Посредник отдельно выполняет шесть согласованных внешних сценариев
(максимум восемь с резервом), визуальную проверку, проверку отзывчивости и
доступности микрофона. Наличие браузера само по себе не подтверждает микрофон.
Новые визуальные и реальные результаты в этом документе не заявлены.

Для собственной приёмки откройте уведомление, задайте вопрос о возможностях,
проверьте ответ по источнику, задайте вопрос об удерживаемом показании и затем
«А теперь?» после нового щипка. Проверьте историю и новый разговор. Технические
проверки не заменяют вашу оценку полезности и пользовательскую приёмку.

## Ассистент разработки

Кнопка «Ассистент разработки» открывает отдельную панель. Пользователь задаёт
цель обычным языком; серверный агентный цикл DeepSeek сам ищет и читает
разрешённые frontend-файлы, готовит изменения, прогоняет фиксированную целевую
проверку (синтаксис изменённых `.js` и/или только изменённые тесты) и применяет
их. После успешного применения страница перезагружается один раз, а
переписка и итог (изменённые пути, diff, результат проверки) восстанавливаются
без повторного выполнения задачи.

Разрешённая область — `web/index.html`, `web/style.css`, `web/src/*.js` (кроме
кода панели ассистента) и прямые `web/test/<имя>.mjs`. Backend, `.env`, секреты,
`.git`, зависимости, `data/`, `tasks/`, `intakes/`, `docs/` и `README.md`
недоступны; граница обеспечивается серверным кодом инструментов. Ключ DeepSeek
не попадает в браузер, инструменты и историю. Commit, push и установка
зависимостей не выполняются. Текст и diff выводятся безопасно, HTML не
исполняется. Подробности и порядок ручной демонстрации — в
[docs/assistant.md](../docs/assistant.md).

Реальные платные вызовы DeepSeek и браузерная/визуальная проверка выполняются
только по отдельному разрешению пользователя.
