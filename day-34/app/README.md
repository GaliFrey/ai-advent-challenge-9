# Guitar Trainer — снимок решения дня 34

Самостоятельный снимок исходников рабочего Guitar Trainer из коммита
`be8282c073f32e9d19c8f9d91fcf457f4840850a`, ветка
`codex/day-34-frontend-assistant`.

Сохранён исходный frontend до демонстрационных правок: задачи с русскими
названиями нот, подсказкой и цветом можно повторить. Рабочие изменения исходного
проекта не включены и не изменены. Runtime-код совпадает с коммитом; в тесте
display.test.mjs удалена лишняя пустая строка в конце без изменения логики;
в публикационном снимке добавлены этот README и .gitignore, а описание
ассистента уточнено по фактическим ограничениям.

Установка: `uv sync --locked`. Ключ `DEEPSEEK_API_KEY` задаётся в локальном
`.env` по образцу `.env.example` или системной переменной. Запуск:
`uv run python -m server.main`, затем http://localhost:8000/ и кнопка
«Ассистент разработки».

Для этого ассистента RAG-модель не требуется. Настройка отдельной панели
«Помощь», команды проверок, сценарий повторения и результаты сдачи описаны
в [README дня 34](../README.md).

Агентные журналы, настройки workflow, секреты, история обращений и локальные
модели исходного проекта в снимок не включены. Они не нужны для работы
ассистента разработки. Подробности реализации — [docs/assistant.md](docs/assistant.md).
