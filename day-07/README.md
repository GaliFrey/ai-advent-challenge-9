# День 7. Сохранение контекста

Терминальное приложение с двумя независимыми LLM-сессиями. Переписка каждой панели хранится в отдельном JSON-файле, восстанавливается после перезапуска и целиком передаётся модели с новым сообщением.

## Как устроено

```text
DualAgentApp
├── left  → Agent → JsonHistoryStore → data/left.json
└── right → Agent → JsonHistoryStore → data/right.json
```

- `Agent` загружает историю при создании и добавляет к ней актуальный системный промпт.
- История не обрезается и не суммаризируется.
- JSON содержит только завершённые пары `user` + `assistant`.
- Запись выполняется через временный файл, `fsync` и атомарный `os.replace`.
- HTTP- и сетевые ошибки, невалидный или незавершённый ответ и сбой записи не меняют историю.
- Повреждённый JSON не перезаписывается молча: приложение останавливается с ошибкой.
- Каждая панель имеет свою двухшаговую очистку. История соседней панели не затрагивается.

Статистика токенов, времени и API-вызовов относится только к текущему запуску. После перезапуска восстанавливаются сообщения, но не метрики прошлых запусков.

## Запуск

Требуются Python 3.11 или новее и `uv`.

```bash
cd ~/Dev/AI_Advent_Challenge/day-07
uv sync --locked
cp .env.example .env
```

Добавь `DEEPSEEK_API_KEY` в `.env` и запусти:

```bash
uv run python main.py
```

`.env`, `data/left.json` и `data/right.json` не добавляются в Git.
