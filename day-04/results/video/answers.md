# Промпты и полные ответы

Серия: `video`.

## Промпт: Факты и расчёты

Роль: `system`

```
Ты выполняешь задание на русском языке. Соблюдай указанный формат ответа.
```

Роль: `user`

```
Исходные данные о вымышленной космической выставке:
Название: Орбита.
Дата: 21 ноября.
Начало: 10:30. Окончание: 17:00 того же дня.
Место: музей Вектор.
Взрослый билет: 480 рублей. Детский билет: 260 рублей.
В группе 3 взрослых и 2 ребёнка.
Скидка на общую стоимость билетов группы: 15%.
Имя экскурсовода не указано.

Извлеки факты и выполни расчёты. Не дополняй исходные данные догадками.
Объект facts должен содержать ровно следующие поля:
- name: название выставки, строка;
- date: дата без добавления года, строка;
- start и end: время в формате HH:MM, строки;
- venue: место в формате «музей Вектор», строка без кавычек-ёлочек;
- duration_minutes: продолжительность в минутах, число;
- total_before_discount: стоимость всех билетов группы до скидки в рублях, число;
- total_after_discount: стоимость всех билетов группы после скидки в рублях, число;
- guide: имя экскурсовода или null, если оно неизвестно.
Верни один JSON-объект без Markdown-ограждений и текста за его пределами.
Верхний уровень JSON должен содержать только ключ facts.
Творческие дополнения не нужны.
```
