# День 4. Температура

## Задание

Выполнить один запрос с `temperature=0`, `0.7` и `1.2`, сравнить точность,
креативность и разнообразие ответов. Формат сдачи: видео и код.

## Эксперимент

Два промпта, по три ответа на каждую температуру — всего 18 API-вызовов:

- `facts` — извлечь факты о выставке и рассчитать продолжительность и стоимость билетов.
- `creative` — придумать слоган и три свободные идеи на тему «Орбита».

Внутри каждой задачи меняется только температура; история ответов не передаётся.
Модель — `deepseek-v4-flash`, thinking выключен, `top_p=1`, `max_tokens=1600`.
Тексты промптов и эталон для проверки находятся в [prompts.py](prompts.py).

## Запуск

```bash
cd ~/Dev/AI_Advent_Challenge/day-04
uv sync
# Если .env ещё нет:
cp -n .env.example .env
```

Укажите `DEEPSEEK_API_KEY` в локальном `.env` или переменной окружения.

Каждая команда делает три новых API-вызова. В начале один раз выводится промпт,
затем все три ответа с токенами и результатом проверки. Команды выполняются по одной:

```bash
uv run python main.py record --prompt facts --temperature 0
uv run python main.py record --prompt facts --temperature 0.7
uv run python main.py record --prompt facts --temperature 1.2
uv run python main.py record --prompt creative --temperature 0
uv run python main.py record --prompt creative --temperature 0.7
uv run python main.py record --prompt creative --temperature 1.2
```

Результаты сохраняются в `results/video/`. Эта сессия уже записана; для повторения
эксперимента добавьте `--session video2` ко всем шести командам. Старые ответы
не перезаписываются.

Сводная таблица без новых API-вызовов:

```bash
uv run python main.py compare results/video --compact
```

Для другой сессии укажите её каталог. Полную новую серию можно выполнить одной
командой `uv run python main.py run` — это 18 API-вызовов.

## Результаты

Серия записана 3 сентября 2026 года с промптами `v3`: получены все 18 ответов,
ошибок API нет. Общий расход — 8451 токен.

| Показатель | T=0 | T=0.7 | T=1.2 |
|---|---:|---:|---:|
| Верные ответы на фактический запрос | 3/3 | 3/3 | 3/3 |
| Уникальные слоганы | 1/3 | 2/3 | 3/3 |
| Уникальные тексты творческих идей | 9/9 | 9/9 | 9/9 |
| Токены: фактический запрос | 1371 | 1382 | 1382 |
| Токены: творческий запрос | 1534 | 1340 | 1442 |

Уникальность считается по тексту: разные формулировки могут описывать одну идею.
Для `facts` проверяются девять полей и расчёты. Для `creative` PASS означает
корректный формат и завершённый ответ, но не оценивает связность или качество идей.

## Вывод

На точных запросах в моём эксперименте температура почти не сыграла роли.
При `0`, `0.7` и `1.2` я получил одинаковые факты и правильные расчёты.
Для таких задач я бы оставил низкую температуру: пользы от её повышения здесь не увидел.

На запросах, где нужна креативность, разница заметнее. При высокой температуре
слоганы стали разнообразнее, но сами идеи не обязательно лучше. При `1.2` модель
предложила опубликовать стихотворение «на корочках питерских снеков с трекером» —
для меня это уже пример несвязного результата. Получается, повышение температуры
может добавить необычности, но вместе с ней и бессмыслицы. Для поиска идей я бы
пробовал среднюю или высокую температуру, а полученные ответы обязательно перечитывал.
