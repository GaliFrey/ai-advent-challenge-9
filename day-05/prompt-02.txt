Разбери код Python 3.11+. Выполнение начинается в новом процессе.

def build(values, history=[]):
    handlers = []
    for value in values:
        history.append(value)
        handlers.append(lambda: (value, tuple(history)))
    return handlers

first = build([1, 2])
second = build([3])
print([handler() for handler in first])
print([handler() for handler in second])

снимок истории после добавления этого значения. При history=None вызовы независимы.

не должны менять уже созданные снимки. Пустой values возвращает пустой список.
