# День 27 — локальная LLM в TUI-чате

## Задание

Интегрировать локальную LLM в приложение: отправлять запросы, получать
и отображать ответы, работать без облачных моделей. Формат сдачи — видео
и код. Оригинал: `resources/task.md`.

## Решение

Самостоятельный Python/uv-проект: Textual TUI и HTTP-клиент Ollama.
Один экран без вкладок: диалог слева, настройки, статистика и сведения
о памяти справа. Нижняя область — многострочный ввод, верхняя — выбор
сессии, открытие, новый диалог и остановка генерации.

Запросы отправляются только на `http://127.0.0.1:11434/api/chat`.
Облачных клиентов, API-ключей и автоматического скачивания моделей нет.
HTTP-прокси из окружения отключены для локального клиента.
Ollama и веса Qwen3 из [дня 26](../day-26/README.md) перенесены
06.10.2026 в каталог дня 27, а 07.10.2026 — в
`day-28/resources/ollama-local/`. Команды ниже используют текущий путь;
приложение не импортирует код предыдущих дней.

Ответ поступает потоком NDJSON, рассуждения отображаются отдельно.
Обновления вывода ограничены десятью в секунду. Если пользователь
прокрутил историю вверх, обновление ответа не возвращает его к концу.
При маленьком терминале боковая панель прокручивается; для записи
рекомендуется полноэкранный терминал примерно 180×60 символов.

## Запуск

Для новой копии репозитория сначала установите Ollama из Linux x86_64
архива (нужны `curl`, `tar`, `zstd` и настроенный драйвер GPU):

```bash
mkdir -p day-28/resources/ollama-local
cd day-28/resources/ollama-local
curl -fL https://ollama.com/download/ollama-linux-amd64.tar.zst -o ollama.tar.zst
tar --zstd -xf ollama.tar.zst
rm ollama.tar.zst
```

Архив по этой ссылке содержит текущий выпуск; в записанном эксперименте
использована версия 0.35.1. Существующая установка уже перенесена из дня 26,
поэтому повторная установка и загрузка весов для неё не нужны.
Установка в папку не является полной изоляцией: служебные файлы могут
появляться в `~/.ollama`.

Из корня репозитория, первый терминал:

```bash
cd day-28/resources/ollama-local
OLLAMA_MODELS="$PWD/models" \
OLLAMA_CONTEXT_LENGTH=8192 \
OLLAMA_NUM_PARALLEL=1 \
OLLAMA_HOST=127.0.0.1:11434 \
OLLAMA_KEEP_ALIVE=30m \
./bin/ollama serve
```

Если модель ещё не скачана, во втором терминале:

```bash
day-28/resources/ollama-local/bin/ollama pull qwen3:14b
```

`serve` запускает сервер; модель загружается при первом запросе.
`ollama list` показывает скачанные модели, `ollama ps` — только загруженные
в память. Для видео выполните `day-28/resources/ollama-local/bin/ollama ps`
после ответа TUI. В команде выше модель остаётся загруженной 30 минут после
запроса; перезапуск сервера очищает загрузку, а следующие запросы загрузят её снова.

Приложение из корня репозитория:

```bash
cd day-27
uv sync
uv run python tui.py
```

Открыть конкретную сессию:

```bash
uv run python tui.py --session sessions/ИМЯ.json
```

Enter отправляет сообщение, Shift+Enter добавляет строку, Escape останавливает
запрос, Ctrl+Q завершает приложение. При выходе активный запрос отменяется,
его частичный результат сохраняется. Модель остаётся загруженной согласно
политике keep_alive Ollama; приложение не останавливает сервер.

## Настройки

Настройки применяются к следующему запросу и записываются в каждый ход.
Во время генерации редактирование блокируется.

| Настройка | По умолчанию | Допустимый диапазон |
| --- | --- | --- |
| Модель | `qwen3:14b` | Имя установленной модели |
| Thinking | Выключен | Включён / выключен |
| Temperature | 0,7 | 0–2 |
| Контекст (`num_ctx`) | 8192 | 2048–32768 |
| Лимит генерации (`num_predict`) | 2048 | 1 — половина контекста |

Лимит генерации включает рассуждения. Если он закончился до текста ответа,
ход сохраняется как `empty` и не попадает в память. Причина завершения
`length` отмечается в диалоге: ответ может быть неполным. Поддержка thinking
зависит от модели; ошибка сервера показывается пользователю. Большой контекст
увеличивает потребление памяти; полный диапазон на GPU не проверен.

## Память и сохранение

Все сессии этого дня хранятся в `day-27/sessions/`, каталог целиком исключён
из Git, включая временные файлы. Настройки, вопросы, ответы, рассуждения,
метрики и параметры отбора истории записываются в JSON. Запись атомарная:
временный файл заменяет предыдущий. Сохранение выполняется перед запросом,
после завершения, ошибки или отмены, перед сменой сессии и при выходе.
Принудительное завершение процесса может потерять последний потоковый текст;
незавершённый ход при загрузке помечается `interrupted`.

Модель получает системную инструкцию, текущий вопрос и последние полные
успешные пары вопрос–ответ. Рассуждения, ошибки, пустые ответы и отменённые
ходы повторно не отправляются. При переполнении оценочного бюджета старейшие
пары исключаются целиком; сохранённая история остаётся полной. Счётчики
в интерфейсе относятся к последнему отправленному запросу.

Для отбора используется консервативная оценка размера UTF-8 плюс запас
на шаблон сообщений и максимальную генерацию. Это **не точный токенизатор**:
заполнение контекста до запроса не выдаётся за измерение токенов. Для иных
моделей оценка не гарантирует отсутствие серверного усечения. Точный
`prompt_eval_count` доступен только в итоговом ответе Ollama.

## Метрики

- Входные токены: `prompt_eval_count` Ollama.
- Сгенерированные токены: `eval_count`, включая thinking.
- Скорость: `eval_count / (eval_duration / 10⁹)` токенов/с.
- Первый фрагмент: время до первого непустого thinking или content.
- Начало ответа: время до первого непустого content.
- Полное время: время запроса по часам клиента; во время генерации — таймер.
- Загрузка модели: `load_duration / 10⁹` секунд.

Скорость появляется после завершения; число сетевых фрагментов не считается
числом токенов. Суммы сессии учитывают только запросы с итоговыми метриками;
отменённые и оборванные запросы могут потребить ресурсы, но не входят в эти
суммы. Входные токены при повторной передаче истории суммируются повторно.

Контракт проверен по [API chat](https://docs.ollama.com/api/chat),
[формату streaming](https://docs.ollama.com/api/streaming) и
[параметрам модели](https://docs.ollama.com/modelfile).

Суммарно обработано 3838 входных и 1955 сгенерированных токенов;
время запросов по часам клиента — 35,010 с. Вход включает повторную передачу

На втором ходе модель выдала отдельные рассуждения: первый фрагмент через

Память темы подтверждена: после запроса убрать рейтинг следующий ответ
сохранил тему приложения для учёта прочитанных книг и сообщил, что функция
оценки отключена. JSON сессии успешно прочитан; сведения об отборе истории
для каждого хода повторно рассчитаны по сохранённым сообщениям и совпали.
Открытие диалога после перезапуска проверено офлайн-тестом; один файл ручной
сессии не доказывает, что перезапуск был выполнен пользователем при записи.

## Выводы и ограничения

Требования ДЗ выполнены: отдельное приложение отправляет запросы локальной
Qwen3 через HTTP Ollama, показывает потоковый ответ и работает без облачных
моделей. Практически подтверждены переключение thinking, метрики и память
актуальной темы и изменения требований. Приложение не гарантирует правильность
ответов модели.

В ручном диалоге есть ошибки качества:

- На вопрос об имени пользователя модель ответила «Меня зовут Влад», затем
  «Нет, меня зовут Влад, а меня зовут Qwen». На пятом ходе исправилась:
  «Ты — Влад, а я — Qwen». Имя сохранилось, но роли в двух ответах перепутаны.
- Модель предлагала дополнительные функции сверх заданных пользователем,
  а Firebase ошибочно называла локальным хранилищем. Эти утверждения не
  используются как технические выводы проекта.
- На седьмом ходе алгоритм исключил первые две пары из запроса, сохранив
  четыре последние. Предыдущий запрос использовал всего 862 входных токена
  при контексте 8192: оценка по байтам ограничивает историю раньше фактического
  заполнения токенового контекста. Полный диалог остаётся в JSON; долговременное
  сохранение всех исходных фактов моделью не гарантируется.

По согласованию с пользователем эти ограничения описаны без изменения
записанного поведения. Высокие значения контекста и другие модели на целевом
GPU не проверены. Визуальная проверка пользовательского терминала и содержания
видео не выполнялась.
