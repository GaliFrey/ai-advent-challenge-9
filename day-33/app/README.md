# Guitar Trainer — снимок решения дня 33

Исходники приложения, пользовательские статьи, тесты и зависимости сохранены
из локального Guitar Trainer, коммит
`0d330682b70e8fac655fa2225d8885e9ceaff5d9`.

Runtime-файлы и зависимости совпадают с исходным коммитом; в одном тесте
удалена лишняя пустая строка в конце файла без изменения логики.

Канонические инструкции установки, запуска, результаты и ограничения этой сдачи:
[README дня 33](../README.md).

Для установки из этого каталога: `uv sync --locked`.
Подготовка модели и индекса: `uv run python -m server.retrieval prepare-model`
и `uv run python -m server.retrieval build-index`.
Ключ задаётся в локальном `.env` по образцу `.env.example`.
Запуск: `uv run python -m server.main`, затем http://localhost:8000/.

Агентные журналы исходного проекта и упоминаемые в технических документах
локальные свидетельства разработки в снимок не включены. Они не требуются
для работы приложения; переписка и диагностические данные создаются локально.
