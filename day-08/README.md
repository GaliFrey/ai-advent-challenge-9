# День 8. Токены и переполнение контекста

Контролируемый семиходовый диалог показывает рост входного контекста, суммарных токенов и стоимости. Последний запрос намеренно превышает настоящее окно модели и получает ошибку API.

## Как устроен эксперимент

- Модель `openai/gpt-3.5-turbo-16k`: окно 16 385 токенов, `max_tokens=32`.
- Агент на каждом ходе отправляет системный промпт, всю завершённую историю и новую реплику.
- `tiktoken` считает текущую реплику и историю до запроса; точные prompt, ответ и стоимость берутся из `usage` OpenRouter.
- Уникальные строки `record_*` детерминированно увеличивают prompt примерно до 1000, 4000, 9000 и 14 500 токенов. Короткие ответы `OK-*` изолируют стоимость входа от длины ответа.
- В середину длинного контекста помещается факт `ORBITA-7429`, который модель должна вспомнить на шестом ходе.
- Context compression и fallback OpenRouter отключены, поэтому превышение окна не скрывается обрезкой или сменой endpoint.
- Неуспешная реплика не добавляется в историю.

Во время работы CLI показывает фрагменты отправляемых реплик, ответы модели и метрики каждого хода. После эксперимента выводятся таблицы контекста и стоимости, автоматический анализ и последствия переполнения.

Параметры модели: [OpenRouter](https://openrouter.ai/openai/gpt-3.5-turbo-16k). Поведение context compression: [документация OpenRouter](https://openrouter.ai/docs/guides/features/message-transforms).

## Запуск

Требуются Python 3.11 или новее, `uv`, API-ключ и положительный баланс OpenRouter.

```bash
cd ~/Dev/AI_Advent_Challenge/day-08
uv sync --locked
cp .env.example .env
```

Добавь `OPENROUTER_API_KEY` в локальный `.env`, затем запусти:

```bash
uv run --locked python main.py experiment --confirm-api-calls --prompt-display preview
```

Предварительный расчёт без API-вызовов:

```bash
uv run --locked python main.py preview
```

JSON-отчёты сохраняются в игнорируемом `resources/results/`. Секреты и заголовок авторизации в них не записываются.

## Результат

Финальный прогон 10.09.2026 выполнил шесть успешных запросов к OpenAI через OpenRouter и один ожидаемый отказ.

| Ход | Сценарий | Текущий запрос | История | Prompt API | Ответ | Цена хода | Накоплено | Результат |
| ---: | --- | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| 1 | короткий | 22 | 101 | 127 | 3 | $0.000393 | $0.000393 | `OK-1` |
| 2 | длинный | 858 | 134 | 996 | 3 | $0.003000 | $0.003393 | `OK-2` |
| 3 | длинный | 2992 | 1003 | 3999 | 3 | $0.012009 | $0.015402 | `OK-3` |
| 4 | длинный | 4987 | 4006 | 8997 | 3 | $0.027003 | $0.042405 | `OK-4` |
| 5 | длинный | 5489 | 9004 | 14 497 | 3 | $0.043503 | $0.085908 | `OK-5` |
| 6 | проверка памяти | 47 | 14 504 | 14 555 | 6 | $0.043689 | $0.129597 | найден `ORBITA-7429` |
| 7 | переполнение | 2823 | 14 565 | локально 17 392 | — | — | $0.129597 | HTTP 400 |

Выводы:

- Prompt вырос в 114,6 раза — со 127 до 14 555 токенов; цена отдельного хода выросла в 111,2 раза.
- На шестом ходе новая реплика занимала 47 токенов, а история — 14 504 токена, или 99,6% prompt. Этот короткий вопрос оказался дороже любого предыдущего хода.
- Текущий контекст достиг 14 555 токенов, но из-за повторной отправки истории API суммарно обработал 43 171 входной токен. Ответы заняли только 21 токен; общий расход составил 43 192 токена.
- Стоимость шести успешных запросов составила $0.129597. Кэш не использовался.
- Локальная оценка prompt совпала с `usage.prompt_tokens` на всех успешных ходах.
- Модель нашла факт в длинном контексте. Prompt из 17 392 токенов превысил окно на 1007 токенов и получил HTTP 400 без ответа и `usage`; история осталась на последнем успешном состоянии.
