# Контрольный набор памяти

`memory.json` содержит 45 вымышленных памяток и 32 вопроса с эталонными источниками,
цитатами и фактами. Личные данные и база рабочего бота не используются.

Из каталога `day-35/app`:

```bash
uv run python -m personal_assistent.evaluate_memory
```

По умолчанию это бесплатная проверка первого FTS-поиска. Отчёт сохраняется
в игнорируемый `evaluations/results/`; `complete` означает завершение процедуры,
а не правильный ответ AI. `first_search.source_coverage` показывает найденные
и пропущенные эталонные источники. Выдача ограничена первой страницей.

`--live` явно включает платные DeepSeek-вызовы и полный агентный процесс.
Для него нужен `DEEPSEEK_API_KEY`; лимиты задаются `--max-calls`,
`--case-timeout`, `--max-tokens`, `--context-budget`, `--context-reserve`.
`--case Q13` выбирает один вопрос, `--output PATH` задаёт новый файл отчёта.
Существующие файлы не перезаписываются. Поля ручной оценки остаются пустыми:
для оценки качества требуется сопоставить ответ с эталонными фактами и цитатами.
Это небольшой фиксированный синтетический корпус, не гарантия точности
на произвольной личной памяти.
