# Сессии агента

Каждый запуск TUI создаёт отдельный JSONL-файл. События идут по времени и
содержат фактические запросы и ответы LLM, вызовы MCP, результаты и финальный
ответ. Эти файлы хранятся в Git вместе с кодом дня 18.

API-ключ и SSH-ключ в журнал не записываются. История содержит вопросы,
имена пользователей и IP-адреса из результатов MCP; перед добавлением новых
сессий в Git проверяйте их содержимое.
